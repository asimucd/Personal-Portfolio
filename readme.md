# 👨‍💻 Mohammed Asim — Personal Portfolio

Welcome to the source code of my personal portfolio website, built to showcase my skills, projects, experiences, and publications in software engineering, machine learning, and full-stack development.

🔗 **Live Site**: [asimucd.github.io/portfolio](https://asimucd.github.io/portfolio)

## 🚀 Features

- **Responsive Design** — Optimized for all screen sizes
- **Project Showcase** — Real-world applications across AI, full-stack, and systems
- **Publication Section** — Research papers with links to journals
- **Experience Timeline** — Detailed work and academic experience
- **Skill Matrix** — Categorized technical skills with visual proficiency
- **Downloadable Resume** — Hosted within the site
- **Contact Section** — Email, social media links, and phone details
